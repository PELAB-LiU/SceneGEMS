# Simulation view

The Simulation view is the primary operations console after a scenario is loaded. It consists of:

- **Scene canvas**: Full-area trajectory visualization (see [Scene canvas](./scene-canvas))
- **Playback bar and rule timeline**: under the canvas, for the preview and the simulation
- **Bottom control panel**: where the run happens and its setup (see [Control panel](./control-panel))
- **Right monitoring sidebar**: one stream at a time (Preview or Simulation): vessel pairs, layers, frame data and charts (see [Monitoring sidebar](./monitoring))
- **Monitor reveal button**: When the right pane is hidden, a floating "Monitor" button on the right edge restores it

Switching to Simulation from another view triggers an automatic camera fit to the current scenario.
